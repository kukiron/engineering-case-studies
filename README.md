# Engineering Case Studies

A collection of engineering case studies from projects I have worked on, focused on frontend architecture, complex product workflows, maintainability, testing, and production delivery.

## Case Studies

### Greywing — Building a dependable crew-change planning workflow

Frontend engineering for maritime crew-planning workflows involving dependent state, progressive flight search, partial results, browser-side querying, end-to-end testing, and concurrent editing.

**Focus:** React, TypeScript, Redux/Context, SSE, AlaSQL, Playwright, WebSockets

[Read the Greywing case study](case-studies/greywing/)

### Ittihad Engineering — From redesign to production

A production website redesign that expanded into frontend maintainability, image-pipeline work, styling conventions, release safety, and production hardening.

**Focus:** Next.js, React, TypeScript, S3, CSS Modules, Tailwind CSS, Netlify

[Read the Ittihad Engineering case study](case-studies/ittihad-engineering/)
